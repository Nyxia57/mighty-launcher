Questions fréquentes
Minecraft ne se lance pas +
Vérifie que Java 21 est bien installé et que tu as alloué au moins 2 Go de RAM dans les paramètres.
Mes mods ne se chargent pas +
Assure-toi que les mods sont compatibles avec ta version de Minecraft et que Forge/Fabric est activé.
Comment mettre à jour le launcher +
Active les mises à jour automatiques dans Paramètres > Général ou télécharge la dernière version sur le site.
